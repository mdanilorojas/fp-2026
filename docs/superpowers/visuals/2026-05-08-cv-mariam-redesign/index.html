Para imprimir o exportar a PDF

Abre cualquiera de los dos archivos y pulsa Ctrl + P. En el diálogo: Destino → Guardar como PDF, Márgenes → Ninguno, Gráficos de fondo → Activados. Tamaño A4 real, listo para enviar. Todo el contenido del CV original está conservado literalmente; sólo cambian tipografía, jerarquía y composición.
